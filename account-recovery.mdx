## 🔁 Recovery Provider

คือเลือกผู้ให้บริการ ที่ต้องการจะกู้บัญชี สมมุติอยากใช้ร้าน XZIN ในการกู้บัญชีไอดีไก่ตันที่เปิดไว้ สมมุติตอนคุณไม่อยู่แล้วไอดีดันติดแคปช่าขึ้นมา แล้วคุณตั้ง ออโต้แก้แคปช่าไว้มันก็จะส่งแก้แคปช่าไปให้ทางร้านนั้นๆ ให้แก้เองเลย โดยที่เราไม่ต้องเสียเวลามานั่งดูและเข้าเว็บไปแก้เอง ซึ่งตอบโจทย์สำหรับคนที่ทำไก่ตันหลายเครื่องเอามากๆ เพียงแค่เติมเงินเข้าระบบเว็ปนั้นค้างไว้ โดย Provider ที่เรารองรับนั้นมีดังนี้

- ร้าน XZIN 
- ร้าน Xenon Hub
- ร้าน First DDC

_หากใครมีร้านแก้แคปช่า/สแกนหน้าที่เป็นของตัวเอง สามารถติดต่อทางเรามาเพื่อให้เพิ่มได้_

## 🔑 วิธีการตั้งค่าให้มันทำงาน

ให้ไปเอา API Key จากทางร้านนั้นมาครับ ตัวอย่างในภาพแรก API Key จากเว็ปไซต์ [xenonhub.pro](https://xenonhub.pro/) และ [xzin-gen.com](https://xzin-gen.com/) มันหน้าตาจะเป็นแบบนี้ แค่คัดลอกคีย์มาและเอาไปใส่ในโปรแกรมของเราได้เลย อย่าลืมติ๊ก Provider ร้านที่คุณใช้ด้วย ไม่งั้นมันจะไม่ตรงกัน หากไม่รู้ว่า API Key ร้านนั้นอยู่ไหน กรุณาติดต่อร้านนั้นเลย

<Warning>
  ใส่ username:password:cookie ให้ครบ ไม่งั้นมันจะไม่ส่งงานเพื่อไปแก้อัตโนมัติให้
</Warning>
