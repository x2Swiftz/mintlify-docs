<Accordion title="⚡ โปรแกรม Storm ปิดเอง แก้ยังไง?">

  หากต้องการให้โปรแกรมเปิดกลับมาอัตโนมมัติ ให้โหลดไฟล์ด้านล่างนี้

  🔗 [**<u>https://m1r.ai/PMRXU.rar</u>**](https://m1r.ai/PMRXU.rar)

  หากตั้ง Setup โปรแกรม Storm ใหม่เรียบร้อยแล้วให้ คลิ๊กขวาทที่ไฟล์ `RazerSynapse.exe` และกด Run as Administrator 
</Accordion>

<Accordion title="🌐  ใช้โปรแกรม Storm แล้วขึ้นเน็ตหลุด (Error Code: 277)">
  ให้ทำการเปิดไฟล์ `config.json` ในโฟลเดอร์ของ Storm และหาคำว่า `use_presence` แล้วเปลี่ยนคำด้านล่างจากคำว่า `true` เป็น `false` แทน จากนั้นให้กด Crtl \+ S เพื่อทำการเซฟไฟล์ที่คุณแก้ไป ทีนี้อย่าลืมเอาไฟล์ `api.luau` ที่อยู่ในโฟลเดอร์ Storm เอาไปใส่ใน AutoExec ของตัวรันที่คุณใช้งานด้วย

  ```javascript
  "use_presence": true,
  
  // ตัวอย่างหลังแก้แล้วต้องเป็นแบบนี้
  
  "use_presence": false,
  ```
</Accordion>
