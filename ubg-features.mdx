## **\[Auto Dodge\]**

└  `หลบการโจมตีอัตโนมัติ ไม่ต้องตั้งค่าเพิ่มเติม เปิดใช้งานไว้เลย`

---

## **\[Dash Punish\]**

└  คำนวนคิดทาง เมื่อคู่ต่อสู้ Dash มา จะให้เราตอบโต้ด้วยอะไร โดยจะมีให้ตั้งตามนี้:

```rust
None → ไม่ตอบสนอง
Block → กดบล็อคให้
Light Punch → ต่อยคลิ๊กซ้ายสวน 
Heavy Punch → ต่อยหนักสวน
Dash Forward → พุ่งไปข้างหน้า
```

## ⭐ คำแนะนำ ⭐

ถ้าหมัดที่คุณใช้ต่อยได้ไม่ไกล ก็ไม่แนะนำให้ใช้การตอบโต้ด้วย `Light Punch` ถ้าเล่นสไตล์แบบ Agressive ก็ตั้ง `Dash Forward` ไปเลยครับ

<video src="/videos/Untitled-Boxing-_8.mp4" controls />

โดยตั้งการตอบโต้เสร็จแล้ว ก็จะมีให้ตั้งอีก 3 แบบนั่นก็คือ

**⬆️ On Front Dash =** `เมื่อศัตรู Dash เข้าหาเรา`

**⬇️ On Back Dash =** `เมื่อศัตรู Dash ถอยหลัง`

**↔️ On Side Dash =** `เมื่อศัตรู Dash ข้าง ซ้าย/ขวา`

---

## **\[Punch & Reactions\]**

└  กำหนดการตอบสนองต่อการโจมตีแต่ละประเภท ที่มีตั้งไว้ก็จะมี

```rust
• None → ไม่ตอบสนอง
• Block → ป้องกัน
• Dodge → หลบ
• Counter Punch → ต่อยสวน
```

## ⭐ คำแนะนำ ⭐

ค่าเริ่มต้นที่ตั้งมาให้จริงๆมันดีอยู่แล้วครับ แต่ถ้าหมัดของคุณตอบโต้หมัดหลอกคู่ต่อสู้ไวกว่า ก็แนะนำให้ตั้ง Counter Trade ไปได้เลย แต่ก็จะมีบางจังหวะที่จะโดนต่อยพร้อมกัน เพราะงั้นลองตั้งดูครับ
