## 🤔 ฟังชั่นนี้เอาไว้ทำอะไร?

เอาไว้สำหรับคนต้องการดูเรียงหลายจอ และที่สำคัญมันช่วยลดการทำงานของ CPU ด้วย เพราะปรับขนาด Size จอ Roblox ลดลง วิธีการใช้งานง่ายๆ ตามด้านล่างนี้เลย

![Screenshot 2026 05 21 231625](/images/Screenshot-2026-05-21-231625.png)

## ✅ เริ่มต้นใช้งานให้เปิด

- 🔓 Unlock Size (ปลดล็อคขนาดจอ)
- ⤵️ Auto Arrange Window
- 🔁 Auto Resize (ปรับขนาดจอให้อัตโนมัติ)

## ⭕ Size Grid

มันเป็นเรียงจอ ว่าต้องการแบบไหน ลองดูตัวอย่างในคลิปด้านล่างนี้ได้เลย
