## ❔ ฟังชั่นนี้เอาไว้ทำอะไร?

เอาไว้สำหรับคนต้องการดูเรียงหลายจอ และที่สำคัญมันช่วยลดการทำงานของ CPU ด้วย เพราะปรับขนาด Size จอ Roblox ลดลง วิธีการใช้งานง่ายๆ ตามด้านล่างนี้เลย

## 🤔 ฟีเจอร์นี้เหมาะกับใคร?

เหมาะกับคนใช้ตัวรัน Volt เพราะถ้าพับจอไว้มันชอบหลุด เราเลยทำฟังชั่นตัวนี้ออกมาให้ แต่ข้อเสียคือการทำงานของ CPU จะมากขึ้นเล็กน้อย ขึ้นอยู่กับสเปคคอมของคุณ ในภาพสเปคคอมคือ

- Xeon 2686 v4 @ 2.40 Ghz
- RAM 128 GB
- RTX 3060
- SSD M.2 1TB
