## ✅ เริ่มต้นใช้งานโปรแกรม

วิธีล็อกอินโปรแกรมใช้งาน ให้คัดลอก API Key ของคุณมาล็อกอิน หากล็อกอินไม่ได้ขึ้นแบบตามรูปภาพด้านล่างนี้แสดงว่าคุณได้คัดลอกคีย์ที่ได้จากซื้อสินค้าในเว็ปมา เพราะงั้นไปเอา API Key มาด้วย 

จากห้อง **<u>#🌩️・storm-panel</u>** จากนั้นกดปุ่ม Download ทีนี้จะมี API Key ปรากฎอยู่ตามรูปภาพที่ 2 ที่แนบไว้

## ⚠️ คำเตือน [สำคัญ ห้ามข้ามขั้นตอนนี้] ⚠️

ให้เอาไฟล์ `api.luau` ในโฟลเดอร์ของ Storm Lauuncher เอาเข้าใส่เข้าไปใน AutoExec ของตัวรันที่คุณใช้งานด้วย ไม่งั้นคุณจะติดปัญหาแน่นอน เช่น ทำไมมันออโต้รีจอยเรื่อยๆไม่หยุด, ทำไมไอดีหลุดแล้วมันไม่กลับมาเปิดต่อให้เป็นต้น

## 👤 Manual Login

คือล็อคอินแบบ ใส่ Username และ Password โดยจะมีแบบใส่รหัสเดี่ยวๆ (Single) หรือถ้าล็อคอินหลายตัว ให้กดเลือกแบบ Multi ไปได้เลย โดยตัวอย่างการใส่รหัสผ่านก็ `username:password` แบบนี้เลย

```text 📃 ตัวอย่างการใส่รหัส โดยบรรทัดละ 1 บัญชี
x2Swiftz:12345678
Androssy:12345678
Alphes_1:12345678
```
